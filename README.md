# 🏦 Python ATM Simulator

## 🚀 What's this project about?
Hey! Welcome to my first official GitHub project. 

This is a fully functional ATM simulator built entirely in Python. Instead of just reading about coding concepts, I built this to get a hands-on feel for how real-world banking logic works behind the scenes. It is my very first portfolio piece as a Semester 1 student at SMIT, designed to put Object-Oriented Programming (OOP) into actual practice.

## ✨ What can it do?
I wrote the logic so it actually functions like a real machine. Here is what you can do:
* **🔒 Secure Login:** You need the right PIN to get access. 
* **💰 Check Balance:** Instantly see how much cash is sitting in the account.
* **💵 Deposit Funds:** Add money to your balance.
* **💸 Withdraw Cash:** Take money out (complete with real-world logic that stops you from withdrawing more money than you actually have).
* **📜 Transaction History:** Prints out a clean mini-statement of your recent activity.

## 🛠️ The Tech Stack
Keeping the code clean and focused:
* **Language:** Python 3
* **Workspace:** Jupyter Notebook (`atm.ipynb`)
* **Core Skills Showcased:** Object-Oriented Programming (Classes & Methods), Control Flow (If/Else logic), and interactive user inputs.

## 💻 How to run it yourself
Want to test it out?
1. Clone this repo to your local machine.
2. Open up `atm.ipynb` in Jupyter Notebook or JupyterLab.
3. Run the cells to fire up the program.
4. Follow the on-screen prompts and try to break the bank!
